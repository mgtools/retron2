## Tools developed for investigating the ARTs (array-associated reverse transcriptases)

# scanner/retron_ncrna_finder.py
A python program for predicting putative ncRNA sequences in a genome. 

# viewer/index.html
Browser based integrated viewer of multiple sequence alignment (MSA) of ncRNAs together with the secondary structure of one of the sequences included in MSA. 
- Input 1: MSA file. The MSA can be generated using whatever approach that works, which can be sequence-based approach, structure-based approach, etc. 
- Input 2: secondary structure in a dot-bracket format. 

See sample files (sample.dot and sample.fasta) under viewer folder. 

Claude.ai was used for the development of these two tools.
